MEP Subject Tracking

Per-subject home range, speed, seasonal, and occupancy analysis for collared wildlife in the Mara ecosystem

Workflow id: mep_collared_report  ·  Mara Elephant Project

This Ecoscope workflow ingests GPS telemetry and collar events from EarthRanger, derives movement ecology metrics via Google Earth Engine, and produces a comprehensive per-subject tracking report — maps, plots, dashboard metrics, CSV tables, and a merged Word mapbook.

  • 3 maps per subject — speed, ETD home range, seasonal home range with MCP overlay
  • 4 time-series plots — NSD, speed, collar events, MCP asymptote
  • 5 dashboard metrics + 3 dashboard tables — movement stats and land-use occupancy
  • A Word mapbook — cover page plus one section per subject
